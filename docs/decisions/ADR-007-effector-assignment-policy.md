# ADR-007 — 타격 자산 자동 선택 점수 정책

## 상태

채택

## 결정

자동 할당은 먼저 안전 후보 필터를 적용하고, 통과한 자산만 결정적 점수로 정렬한다.
후보는 현재 effector 역할·세션, 유효 lease와 Heartbeat 연결, Pose 동기화, 최신 status,
필요 capability, 정상 상태, 비공격 상태, Pan/Tilt 도달 가능성을 모두 만족해야 한다.
동시 작업을 지원하지 않는 자산에 활성 할당이 있으면 후보에서 제외한다.

기본 점수는 다음 항목의 가중합이며 낮을수록 우선한다.

- 자산 Pose에서 track까지의 3차원 거리
- 현재 Pan/Tilt에서 계산된 목표 Pan/Tilt까지의 최단 회전량
- 현재 활성 할당 수
- degraded 고정 penalty
- 최근 명령 실패 횟수

모든 가중치는 실행 설정으로 바꿀 수 있는 0 이상의 유한값이어야 한다. 같은 점수이면
가장 작은 `asset_id`를 선택한다. 필터 및 점수 계산은 UDP 송신이나 mutable registry와
분리된 순수 함수로 유지한다.

## 할당 상태와 재할당

`AssetAssignmentService`는 후보 점수 계산과 자원 점유를 하나의 mutex 임계구역에서
수행해 배타 자산의 동시 이중 할당을 막는다. 수동 지정도 같은 안전 필터를 통과해야
한다.

공격 시작 전 자산이 fault 또는 연결 단절되면 할당을 `assignment_lost`로 바꾸고 해당
track을 재할당할 수 있다. 공격이 시작된 뒤 같은 상황이 발생하면
`operator_action_required`로 전환하고 기존 자산·세션을 보존한다. 이 상태에서는 다른
자산으로 자동 인계하거나 운영자 unassign을 허용하지 않는다.
