# ADR-004 — 전역 track_id와 원본 관측 식별자

## 상태

채택

## 결정

C2 내부의 활성 표적은 0이 아닌 64비트 `track_id`로 식별한다. 원본 측정의
식별자는 `(observation asset_id, observation session_id, detection_id)` 복합 키로
유지한다. 같은 복합 키의 새 측정은 기존 track을 갱신하며, 서로 다른 자산이나
세션의 같은 `detection_id`는 별도 track을 만든다.

`track_id`는 C2 프로세스가 설정된 시작값부터 순차 발급한다. 최댓값 이후에는 1로
순환하되 0과 현재 활성 ID는 건너뛴다. 서버 재시작 뒤 ID가 재사용될 수 있으므로,
외부 영속 시스템은 C2 인스턴스 식별자나 발생 시각과 함께 보관해야 한다.

track은 C2 수신 시각을 기준으로 설정된 유효기간 후 제거한다. 전체 및 관측 자산별
보관 상한을 모두 적용하고, 목록은 `track_id` 오름차순으로 반환한다. 측정 시각이
같은 동일 sequence는 중복으로 허용하고, 더 오래된 측정은 최신 상태를 덮어쓰지
못한다.

## 범위

이번 결정은 서로 다른 관측 자산의 측정을 자동 융합하지 않는다. 원본 식별자와
측정 전체를 보존하므로 이후 별도의 융합 서비스가 여러 track을 연관시킬 수 있다.
