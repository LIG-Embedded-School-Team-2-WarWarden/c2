# ADR-002: 시연 런타임 기본값과 명령 식별 규칙

- 상태: 채택(교육용 시연 기준)
- 일자: 2026-09-27
- 범위: C2 서버와 더미 관측·타격 자산

## 배경

ICD에는 하트비트 주기, 단절 판단, 최대 표적 수와 일부 오류 코드가 TBD로
남아 있다. 또한 `CommandAck`에는 원래 명령 종류가 없으므로
`EffectorTurretCommand`와 `AttackCommand`가 각각 같은 `command_id`를 발급하면
ACK를 유일하게 대응시킬 수 없다.

## 결정

1. 타격 자산으로 보내는 `EffectorTurretCommand`와 `AttackCommand`는 하나의
   `command_id` 및 메시지 `sequence` 발급 공간을 공유한다.
2. C2와 각 자산은 1초마다 양방향 Heartbeat를 보낸다. 마지막 Heartbeat 수신 후
   3초를 초과하면 연결 단절로 판정한다.
3. 통신 단절 시 C2는 신규 일반 명령을 차단하고 재연결 후 `AssetPose`를 다시
   받아야 한다. 더미 관측 자산은 탐색을 정지하고, 더미 타격 자산은 무장과
   공격 출력을 해제한다.
4. `EMERGENCY_STOP`은 동일한 `command_id`로 UDP 데이터그램을 3회 전송한다.
   자산은 같은 ID를 재수신하면 기존 결과를 반환하여 동작을 중복 실행하지 않는다.
5. 시연 기본값은 자산 상태 100 ms, Heartbeat 1 s, 표적 좌표 1 s,
   표적 유효시간 2 s, 최대 동시 표적 256개다.
6. 더미 자산은 시작 및 매 Heartbeat 주기에 `AssetPose`를 재전송한다. 이는 실행
   순서가 달라도 자동 동기화하기 위한 시뮬레이터 편의 동작이며 실제 자산은 초기화,
   설정 변경, 재연결 시 전송한다.
7. 더미 자산 오류 코드는 `0x4001 EXPIRED_COMMAND`,
   `0x4003 INVALID_COMMAND`, `0x4004 INVALID_STATE`,
   `0x5001 NOT_ALIGNED`, `0x5002 NOT_ARMED`를 사용한다.
8. 정의되지 않은 enum은 공격·구동 상태를 추측하지 않도록 현재 프로토콜 버전에서
   메시지 검증 실패로 처리한다. 향후 `UNKNOWN` 전달이 필요하면 명시적인 상태와
   안전 동작을 스키마에 추가한다.

## 영향

이 값은 하드웨어 성능 기준의 최종 승인값이 아니다. 실제 장비 시험 결과로 ICD의
TBD가 확정되면 구성 파일이나 명령행 옵션으로 외부화하고 이 ADR을 대체한다.
전역 타격 명령 ID 규칙은 현 `CommandAck` 스키마를 유지하는 동안 호환성 요구사항이다.
